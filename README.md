# Hexapod.info

Static GitHub Pages site for hexapod biology, robotics, projects, community, and learning resources.

## Publish

1. In **Settings → Pages**, choose **Deploy from a branch**, then select the default branch and `/ (root)`.
2. In **Settings → Pages → Custom domain**, enter `hexapod.info`. The included `CNAME` file preserves that setting.
3. At the DNS provider for `hexapod.info`, create the GitHub Pages records shown in GitHub's custom-domain instructions, then enable **Enforce HTTPS** after the DNS check succeeds.

The comparison picker in `app.js` works entirely in the browser. The gallery uses gradients and illustrations, so the site has no external image licensing dependency.
